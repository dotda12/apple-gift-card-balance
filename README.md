## The fine print that decides whether your $10 works

None of the following appears on Apple's marketing page, and all of it decides whether your purchase is usable.

1. **Region lock.** The Amazon Spain listing states plainly: "Valid only for transactions on Apple properties in Spain." US resellers state the mirror-image rule, that the account region must be set to the United States. A Spanish code redeemed on a US account is dead weight, and there's no conversion desk.
2. **No refunds, no exchanges.** "Apple Gift Cards cannot be exchanged or returned." The legal text adds that resale, return or exchange isn't permitted except where the law requires it. Buying the wrong region isn't a valid reason for a refund under those terms.
3. **No expiry.** The same terms say "Does not expire," and Walmart's FAQ repeats it with no fees attached. You don't have to spend it this month, which removes the main reason to rush a decision.
4. **The code is the money.** "Beware of gift card scams. Don't share your code," and "Apple is not responsible for its use without authorization." Anyone who has the 16-digit code can redeem it. There's no name attached and no way to prove it was yours.
